# Material de Práctica y Teoría

## 1. Introducción y Contenidos
Este archivo consolida y describe el material de práctica general y los apuntes teóricos fundamentales que se encuentran en la nueva carpeta de `Material Estudio`. Aquí no se listan exámenes formales, sino herramientas de preparación, cuestionarios de preguntas frecuentes y guías de ejercicios (principalmente en SQL y teoría general).

## 2. Análisis Descriptivo
El contenido se distribuye mayoritariamente en documentos de texto (`.docx`), scripts (`.sql`) y un apunte maestro en formato PDF. 
- **Estructura del material:** Se divide claramente en dos ramas: práctica intensiva de sintaxis SQL aplicada (mediante el modelo de "Jardinería") y recopilación de conocimientos teóricos (preguntas frecuentes y diapositivas teóricas).
- **Utilidad:** Es el paso previo y necesario antes de enfrentarse a los parciales y finales. Sirve para afianzar la memoria mecánica de las consultas y para asentar los conceptos arquitectónicos del DBMS.

## 3. Guía de Contenidos y Resoluciones

A continuación se detalla el contenido específico de los archivos de práctica hallados:

*   **`Teoria Importante.pdf`**
    *   **Contenido:** Es una presentación magistral (más de 120 diapositivas) que cubre de manera visual y estructurada toda la teoría de la segunda mitad de la materia.
    *   **Temas que incluye:** Almacenamiento físico y volumetría, Índices (B+, Bitmaps, Hash), Managers de la arquitectura (File, Cache, Disk, Transaction), Transacciones (ACID, Schedules), Concurrencia (Strict 2PL, Deadlocks), Técnicas de Recuperación (Actualización Diferida, Inmediata, Shadow Paging), Optimización de Consultas (Cálculo de costos, algoritmos de JOIN), y Seguridad en DBMS (DAC, MAC, Roles, Vistas, GRANT/REVOKE).
*   **`Practica-SQL-Jardineria (1).sql`** y **`Práctica SQL Jardinería (1).docx`**
    *   **Contenido:** Archivos dedicados a la resolución de consultas SQL utilizando un esquema de base de datos clásico ("Jardinería"). Contiene el código fuente SQL para crear y popular las tablas, así como las resoluciones a las consignas de práctica.
*   **`Preguntas frecuentes BD Revisado.docx`**, **`Preguntas teoricas Base de datos.docx`** y **`Preguntas teoricas Base de datos.pdf`**
    *   **Contenido:** Documentos elaborados para el repaso conceptual rápido. Incluyen listados de preguntas teóricas comunes (sobre modelado, índices, formas normales y álgebra relacional) que suelen ser la base teórica de la que se extraen preguntas para evaluaciones cortas o justificaciones en la práctica.
